Blokada plików systemowych

Następujące lokalizacje są chronione przed usunięciem lub przeniesieniem przez naszą aplikację:

🔒 Cały główny katalog C:\ (nie można przenieść samego dysku)
🔒 System operacyjny: C:\Windows
🔒 Pliki programów: C:\Program Files oraz C:\Program Files (x86) (podkatalogi Microsoft)
🔒 Dane aplikacji systemowych: C:\ProgramData
🔒 Dane użytkowników i przeglądarek: C:\Users\<Nazwa>\AppData\Local oraz Roaming
🔒 Pliki pamięci wirtualnej: pagefile.sys, hiberfil.sys, swapfile.sys
